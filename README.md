# Trove TON Portfolio UI

Fresh UI prototype for a Telegram Mini App portfolio tracker covering Telegram gifts, Telegram stickers, and TON tokens.

## Screens

- Portfolio overview
- Holdings and allocation
- Market view
- Wallet/profile

## Preview

Open `index.html` directly in a browser, or serve the folder locally:

```powershell
cd "C:\Users\vishu\Documents\New project\ton-portfolio-ui"
python -m http.server 5177
```

Then visit:

```text
http://localhost:5177
```
