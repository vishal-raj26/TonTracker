# TonTrack Visual Direction

Redesign TonTrack as a premium mobile portfolio tracker for TON tokens, Telegram Gifts, and NFT sticker packs.

Use TonTrack screenshots as the source of the existing information architecture and content. Use the attached collectible-app reference only for visual direction: refined mobile typography, generous whitespace, soft rounded cards, large art-led moments, restrained chips, and a floating bottom navigation.

Do not copy the reference app's branding, character art, marketplace language, bid controls, countdowns, heart buttons, layouts, or exact colors. TonTrack must remain a private portfolio product, not an NFT marketplace.

## Visual System

- Primary background: deep graphite/navy-black, never pure black.
- Elevated surfaces: calm charcoal cards with a subtle 1px border. Avoid strong glass, excessive gradients, and heavy shadows.
- Text: clean rounded modern sans-serif similar to SF Pro Display or Manrope. Headlines are confident but compact; secondary text is muted gray.
- Accent colors: blue for tokens, teal for stickers, gold for gifts and the small Estimated status pill. Use green/red only for movement.
- Spacing: use an 8px rhythm. Screen padding 16-20px, card padding 16px, and 16-24px between major sections.
- Corners: 20-24px for important cards; 14-16px for smaller controls. Use pill chips only for filters, traits, and status.
- Collectible art: show the original PFP/artwork fully inside a large rounded artwork frame with breathing room. Never crop the main artwork tightly.
- Keep one clear visual focus per screen. Do not overload screens with bento grids, badges, decorative gradients, or duplicate information.
- Navigation: use a floating dark rounded capsule. The selected tab is an off-white circular or oval pill.
- Information hierarchy: title first, value second, supporting context third. Never repeat collection and model names unnecessarily.
- States: loading, unavailable, live floor, backdrop floor, and estimated values must be visually distinct but quiet. Show Estimated only as a small gold pill, not repeated in supporting copy.
