# Wallet Ideas: Current Concept Filter

Updated: 22 September 2026

This file overrides earlier idea-selection heuristics when they conflict with the rules below. Earlier research remains useful as evidence, but its shortlists are not binding.

## Required pattern

Use Wallet Replay as the quality reference.

A concept must:

1. Start from a real moment in an existing Wallet journey.
2. Add a new user action or understanding without replacing the existing feature.
3. Use data, execution history, positions, assets, contacts, notifications or controls Wallet already possesses.
4. Be explainable through one decisive button, card, view or interaction.
5. Create an immediate emotional response: "I would use that" or "I have needed that."
6. Have a narrow first version that Wallet could ship without becoming a different company.
7. Be visually demonstrable in one product mockup.
8. Differ materially from both Wallet's live functionality and contest comments.

## Automatic rejection

Reject concepts that:

- turn Wallet into an unrelated telecom, ticketing, insurance, identity, science, data or creator marketplace;
- rename or replace Earn, transfers, P2P, trading, rewards or another existing feature;
- offer only fewer taps, a dashboard, an AI summary, an alert, a calculator or generic automation;
- depend on a large external partner network before the user receives value;
- are infrastructure ideas without a compelling user moment;
- are trendy only because the category is receiving attention;
- require a long explanation before the benefit becomes interesting;
- duplicate a submitted contest idea even if the wording or branding differs.

## Research sequence

For every new candidate:

1. Name the exact existing Wallet screen and moment where it appears.
2. State the unmet question, frustration or decision at that moment.
3. Define the single new interaction.
4. Show why Wallet already has the information required to power it.
5. Check Wallet announcements and the live product for existing coverage.
6. Check contest comments using the core mechanism and likely synonyms.
7. Check recent external products only for evidence of behavior or interaction, not for categories to copy.
8. Draft only after the candidate passes all seven checks.

## Quality test

Complete this sentence before retaining an idea:

> After I ______ in Wallet, I can now ______, using information Wallet already has, so that I ______.

If the sentence is generic, describes an existing function, or requires a new external business, reject the idea.
